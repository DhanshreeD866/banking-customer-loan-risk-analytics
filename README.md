# Banking Customer & Loan Risk Analytics

This project focuses on analyzing **customer and loan data** to identify customers who may have a higher risk of loan default.

I built this project to understand how data analytics can be used in the **banking and lending domain** to study customer behavior, loan patterns, and financial risk.

The project covers the complete analytics process, starting from data cleaning and SQL analysis to Python EDA and an interactive Power BI dashboard.

##  Project Objectives

The main objectives of this project are:

* Analyze customer and loan information
* Identify factors related to loan defaults
* Find high-risk customers
* Understand loan performance across different customer groups
* Analyze default rates based on factors such as age, income, loan grade, home ownership and loan intent
* Create an interactive dashboard for easy decision-making
* Generate useful insights that can help in risk assessment


##  Tools & Technologies

* **Python** – Data cleaning and Exploratory Data Analysis
* **Pandas** – Data manipulation
* **Matplotlib & Seaborn** – Data visualization
* **MySQL** – SQL analysis and advanced queries
* **Power BI** – Interactive dashboard and data visualization
* **Excel** – Initial data checking and preparation
* **Jupyter Notebook** – Python analysis


##  Project Workflow

The project was completed in the following stages:

### 1. Data Understanding

I first explored the dataset to understand the available customer, loan and risk-related information.

### 2. Data Cleaning

The data was checked for:

* Missing values
* Duplicate records
* Incorrect data types
* Unwanted spaces and characters
* Inconsistent categorical values

The cleaned data was then prepared for further analysis.

### 3. SQL Analysis

I used MySQL to perform different levels of analysis, including:

* Customer segmentation
* Loan status analysis
* Default rate analysis
* Risk category analysis
* Income and loan amount analysis
* Loan grade analysis
* High-risk customer identification

I also used advanced SQL concepts such as **CTEs, subqueries, CASE statements, aggregate functions and window functions**.

### 4. Python EDA

Python was used to explore the data in more detail.

Some of the analysis included:

* Distribution of customer age
* Income analysis
* Loan amount analysis
* Loan interest rate analysis
* Default rate analysis
* Risk patterns
* Customer and loan segmentation
* Relationship between different risk factors

Visualizations were created to make the patterns easier to understand.

### 5. Power BI Dashboard

Finally, I created an interactive Power BI dashboard to present the important findings.

The dashboard allows users to explore:

* Total customers
* Total loans
* Defaulted customers
* Default rate
* Loan amount
* Customer risk levels
* Loan grades
* Loan purposes
* Customer demographics
* High-risk customer segments

Interactive slicers are included so that the analysis can be filtered based on different customer and loan attributes.
